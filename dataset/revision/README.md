# Revision data for paper 1571345184

`raw/jeneponto_2024.xlsx` is the unchanged 2024 workbook from Asmaul Husna RS et al., *Dataset Stunting and Nutritional Status of Toddler from Jeneponto Regency, South Sulawesi, Indonesia*, Mendeley Data version 4 (2026), DOI [10.17632/wzwpc9j5bx.4](https://data.mendeley.com/datasets/wzwpc9j5bx/4), licensed CC BY 4.0. Its source checksum and download URL are recorded in `raw/jeneponto_manifest.json`. The cohort is regional and does not establish national representativeness.

`raw/who/` contains six unchanged WHO monthly Excel reference tables, downloaded through the official WHO length/height-for-age and weight-for-age pages. Source URLs and SHA256 values are in `references/manifest.json`. `references/who_monthly_corrected.csv` combines length below 24 months with height from 24 months; overlapping month-24 rows are never averaged. Every legacy LMS coefficient is compared in `references/legacy_vs_primary_who_coefficients.csv`. The original repository reference files remain unchanged.

`derived/jeneponto_2024_harmonized.csv` retains all 31,740 nonempty source observations. Date-typed weight cells are restored only from their explicit Excel display format `d\.m`: the calendar day and month form the displayed decimal measurement. No unknown formats, missing measurements, or possible gram/kilogram errors are estimated. The binary source status is retained; discrepancies with recomputed HAZ are audit results, not exclusions. Task-specific validity masks preserve otherwise valid HAZ observations when weight is invalid, and vice versa. Primary external evaluation is restricted to completed months 0–23; month 24 is a sensitivity cohort. `No.`/`Source_Row` identifies a source row, not a verified unique child.

HAZ/WAZ are recalculated against the audited monthly tables. Corrected WAZ uses the WHO restricted LMS tail rule beyond three standard deviations; legacy comparisons preserve the original plain-LMS implementation. These are monthly reference approximations, not exact-day clinical gold standards. Measurement position is absent: values remain as recorded, with the declared age-based reference convention and no invented 0.7 cm conversion. Source Z-scores that can be read without reconstructing dates are retained separately for inspection.

`audits/` contains synthetic and external data summaries. Reproduce with `python -m analysis.revision.data`; cached sources are used on subsequent runs. All downloaded data and references are used solely for source verification and external evaluation of contemporaneous anthropometric assessment, not future-risk or causal inference.
